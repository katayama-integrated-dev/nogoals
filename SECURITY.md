# Security

## Reporting a vulnerability

Send vulnerability reports to security@katayama.dev. Do not open a public
GitHub issue for a vulnerability.

Include what you found, the version or commit you tested, and the steps or
input that reproduce it.

## Supported versions

We fix security issues in the latest tagged release only.

## What to expect

We reply to acknowledge the report and follow up as we investigate. When a
fix ships, the release notes say so.
